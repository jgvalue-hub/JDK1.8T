# 화면 20개

URL 앞에는 배포 컨텍스트 `/workhub`를 붙입니다. 공통 레이아웃과 템플릿을 재사용하며 다음은 사용자가 수행하는 독립 화면입니다. 등록/수정은 `id` 유무에 따른 동일 화면 모드입니다.

| 번호 | 화면 | 경로 | 동작 / 권한 |
|---|---|---|---|
| 1 | 로그인 | `/login` | 세션 인증, 실패 메시지 |
| 2 | 대시보드 | `/dashboard` | DB 실시간 집계, 최근 업무·공지 |
| 3 | 내 정보 | `/profile` | 이름·이메일 수정, 현재 비밀번호 확인 후 변경 |
| 4 | 사용자 목록 | `/users` | 검색·페이징, 관리자 |
| 5 | 사용자 등록/수정 | `/users/edit?id=…` | 계정·역할·부서·활성 관리, 관리자 |
| 6 | 부서 관리 | `/departments` | 한 화면 등록·수정·삭제, 관리자 |
| 7 | 거래처 목록 | `/clients` | 검색·페이징 |
| 8 | 거래처 등록/수정 | `/clients/edit?id=…` | 수정·삭제, 매니저 이상 |
| 9 | 프로젝트 목록 | `/projects` | 검색·페이징 |
| 10 | 프로젝트 등록/수정 | `/projects/edit?id=…` | 담당자·거래처·마감일·상태 |
| 11 | 프로젝트 상세 | `/projects/{id}` | 상세 조회, 권한별 수정·삭제 |
| 12 | 업무 목록 | `/tasks` | 검색·페이징 |
| 13 | 업무 등록/수정 | `/tasks/edit?id=…` | 프로젝트·담당자·마감일·상태 |
| 14 | 업무 상세 | `/tasks/{id}` | 상세 조회, 연결 프로젝트, 수정·삭제 |
| 15 | 내 승인요청 | `/approvals` | 본인 요청만 검색·페이징 |
| 16 | 승인요청 작성/수정 | `/approvals/edit?id=…` | 승인자 지정·임시저장 |
| 17 | 승인함 | `/inbox` | 지정된 미처리 요청, 매니저 이상 |
| 18 | 승인 상세/처리 | `/approvals/{id}` | 작성자 상신, 지정 승인자 승인·반려 |
| 19 | 공지사항 | `/notices` | 검색·페이징·본문 조회, 매니저 이상 인라인 CRUD |
| 20 | 감사로그 | `/audit` | 대상 검색·페이징, 관리자 읽기 전용 |

존재하지 않는 자료는 404, 미인가 접근/CSRF는 403, 입력 오류는 400, 상태·버전·참조 충돌은 409로 반환합니다. 오류 화면에서 브라우저 뒤로 가기로 입력값을 확인할 수 있습니다. 별도 모달·스크립트 없이 HTML 기본 폼을 사용합니다.
