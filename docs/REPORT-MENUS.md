# 50개 주요 업무 메뉴

10개 영역 × 5개 보고서 = **50개**. 등록·상세·수정·휴지통은 각 메뉴 안의 기능이며 별도 주요 메뉴로 세지 않습니다. 기존 사용자·부서·거래처·프로젝트·업무·공지·감사 및 대시보드는 보조 도구로 보존합니다. 모든 수치·산식은 **데모 예시**이며 규제·재무 판단을 대신하지 않습니다.
